How lazy-ram works

lazy-ram times one hash-map lookup at a time, with an idle gap (sleep_usec) before each. Every lookup is a main-memory access. If lookups get slower as the gap grows, memory is going to sleep between accesses. These three figures show one run step by step, which parts talk to what, and the effect the benchmark is looking for.
